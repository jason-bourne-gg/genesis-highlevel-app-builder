# HighLevelAssignMent

A Node.js project scaffolded for the HighLevel assignment.

## Status

Early stage — the repository currently contains the base setup (Node `.gitignore`, MIT license) and this README. Implementation is in progress.

## Requirements

- [Node.js](https://nodejs.org/) 18 or newer
- npm (ships with Node)

## Getting Started

```bash
git clone git@github.com:jason-bourne-gg/HighLevelAssignMent.git
cd HighLevelAssignMent
npm install
npm start
```

## Project Structure

```
.
├── .gitignore    # Node ignores (logs, node_modules, env files, build output)
├── LICENSE       # MIT

```
